# Geo-Clean Automation Framework 🚀

## Overview
**Geo-Clean** is a smart facility management platform designed to track personnel movement via QR code scans and monitor attendance.  
This repository contains a robust **End-to-End (E2E) Automation Framework** built to ensure the reliability of the Geo-Clean Admin Console.

The framework automates critical workflows such as:

- Admin management
- Cleaner registration & management
- Real-time intelligence reporting

## 🧪 Key Test Scenarios

- **Authentication:** Secure Admin login & registration flows  
- **Staff Registry:** Add, update, and delete cleaning personnel  
- **Deployment Matrix:** Assign staff to facility authorization nodes  
- **Intelligence Logs:** Verify date-filtered reports for audit purposes  
- **Live Tracking:** Validate real-time location fetching for on-site staff
